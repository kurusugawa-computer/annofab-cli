# 全般
* 異なるコマンドで、同じオプションについての詳細な説明が必要な場合は、同じ内容を繰り返すのではなく、リンクを利用してできるだけ共通化してください。メンテナンスコストを下げるためです。
* ユーザーが利用するために必要な公開仕様を記載する。内部的な処理は、明示的に仕様として保証する場合を除いて記載しない。

* ファイルを出力するコマンドでは、出力結果の例を必ず示してください。CSVとJSONの両方の形式で出力例を示してください。
    * CSV形式での出力例では、`:file:`オプションを使用して、出力ファイルを指定してください。
