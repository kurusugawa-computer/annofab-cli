## はじめに

以下のコマンドでインストールできます。

```
$ pip install annofabcli
```

動作環境、認証情報の設定、初回の動作確認は、[Getting Started](https://annofab-cli.readthedocs.io/ja/latest/user_guide/getting_started.html)を参照してください。
